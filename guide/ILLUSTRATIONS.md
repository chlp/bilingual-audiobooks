# Иллюстрации: библия -> референсы -> сцены

Генератор картинок не помнит прошлые картинки. Если каждую сцену описывать
словами, у героини будут разные косички, домик станет то красным, то
жёлтым, а воздушный змей — ромбом в одной главе и треугольником в другой.
Поэтому всё, что повторяется, сначала фиксируется **картинкой-референсом**,
и каждая сцена генерируется с прикреплёнными референсами.

Роли:
- **Claude** (главная сессия) читает книгу, пишет библию и сцены, проверяет
  результат. Картинки не рисует.
- **Codex** (приложение Codex, skill `imagegen`) генерирует картинки по
  файлам, которые написал Claude, и сам отсеивает явный брак.
- **Человек** выбирает варианты референсов и смотрит готовые сцены.

## Файлы

```
illustrations/
  bible.md            стиль + персонажи + локации + предметы (Claude)
  refs/
    characters-v1.png …   варианты листа персонажей (Codex)
    loc-<id>-v1.png …     варианты локаций
    prop-<id>-v1.png …    варианты предметов
    _variants.png         контакт-лист для выбора
    characters.png        ЗАФИКСИРОВАННЫЕ референсы (копия выбранного варианта)
    loc-<id>.png
    prop-<id>.png
  scenes.json         сцены: глава, якорь, референсы, промпт (Claude)
  chNN/MM.png         сцены (Codex), 3:2, PNG
  web/chNN/MM.jpg     уменьшенные копии для плеера (build_html.py, не править)
```

## Шаги

### 1. Библия — Claude

`prompts/claude-bible.md`. Что попадает в библию:

- **Персонажи** — все, кто есть в 2+ сценах, включая животных. Сначала
  факты из текста (с цитатой и главой), потом придуманное. Одежда
  постоянная — меняется только по сюжету (пижама, куртки зимой), и это
  пишется в сцене.
- **Локации** — места 2+ сцен: дом героя, комната, школа, площадка,
  домик на дереве. Архитектура, цвета, ключевые детали.
- **Предметы** — повторяющиеся и сюжетные: игрушка, изобретение, машина
  папы, рюкзак, воздушный змей. Форма, цвет, узнаваемые детали.
- **Стиль** — одна строка для всех картинок + 1–2 альтернативы для
  вариантов.
- **Правила** — кого генератор склонен дорисовывать (в Robin в сценах, где
  папы Молли не было, он появлялся в 4 из 8 картинок главы 10), кого легко
  спутать.

Эпизодические персонажи и места (1 сцена) описываются прямо в сцене, без
референса.

### 2. Варианты референсов — Codex

`prompts/codex-refs.md`: 3 варианта листа персонажей (один в
альтернативном стиле), по 2 варианта на локацию и предмет. Ничего не
перезаписывается. В конце — контакт-лист `refs/_variants.png`.

### 3. Выбор и фиксация — человек + Claude

Смотрим `_variants.png`, выбираем по каждой группе. Мелкие правки
(«v2, но причёска из v1») — отдельным запросом к Codex на доработку
выбранного варианта. Затем:

```bash
cd books/<slug>/illustrations/refs
cp characters-v2.png characters.png
cp loc-stuga-v1.png loc-stuga.png
cp prop-drake-v2.png prop-drake.png
```

Claude обновляет `bible.md`: статус LOCKED, описания уточнены по
выбранным картинкам (если на референсе у дедушки синяя шапка, а в тексте
библии красная — правится библия, не картинка). После фиксации описания
больше не меняются.

### 4. Сцены — Claude

`prompts/claude-scenes.md` -> `scenes.json`. Каждая сцена:

```json
{"id": "02-02", "chapter": 2, "file": "ch02/02.png", "pos": "after",
 "anchor": "Змей летит всё выше и выше",
 "refs": ["characters", "loc-kulle", "prop-drake"],
 "title": "Змей над холмом",
 "prompt": "On top of the grassy hill ... Ella's mother is NOT in this scene."}
```

`anchor` — уникальный фрагмент строки перевода (или `anchorOrig` —
оригинала): плеер ставит картинку после (`after`) или перед (`before`)
этой строкой в обеих колонках, клик по картинке перематывает аудио к ней.
Промпт описывает только действие и композицию: внешность — из референсов.

Проверка: `python3 tools/illustrations_status.py books/<slug>` — якоря,
незафиксированные референсы, список недостающих картинок.

### 5. Генерация сцен — Codex

`prompts/codex-scenes.md`. Codex прикрепляет `refs/<id>.png` из поля
`refs`, генерирует по главам, после каждой главы смотрит контакт-лист и
сам перегенерирует явный брак.

### 6. Проверка — Claude, исправления — Codex

`prompts/claude-review.md`: Claude сравнивает контакт-лист с библией и
текстом и выдаёт готовый промпт `codex-fix.md` со списком сцен и
конкретными правками. Затем `python3 tools/build_html.py books/<slug>`.

## Советы

- 3–6 сцен на главу достаточно; ребёнку важнее картинка на каждом
  развороте внимания, чем много похожих.
- Не ставить две сцены с одинаковой композицией подряд.
- Сцены с толпой (класс, праздник) — самые ненадёжные: в промпте назвать
  главных героев и их место в кадре, остальных — «background children,
  not detailed».
- Если персонаж по сюжету переодевается надолго (зима), сделать отдельный
  референс `characters-winter.png` и ссылаться на него в зимних сценах.
- Обложка: отдельная сцена без якоря не нужна — `book.json` -> `cover`
  с путём к любой картинке; используется в каталоге сайта.
