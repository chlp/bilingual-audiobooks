# Что ещё улучшить

Уже сделано при объединении двух проектов (Robin + Sandvargen):

- один плеер для всех маршрутов: иллюстрации, режим одного языка,
  исправления для iPad, запоминание места (глава, время, прокрутка),
  ссылка на место (`#t=`, `#ch=`), скорость/шрифт/язык запоминаются,
  пробел — пауза, Media Session (название главы на экране блокировки);
- `book.json` вместо длинных командных строк, все пути относительно книги;
- библия иллюстраций: не только персонажи, но и локации и предметы,
  у каждого свой референс; варианты для выбора; `scenes.json` с
  референсами на каждую сцену; проверка якорей и референсов;
- PDF из того же `data.json` с иллюстрациями: параллельный и книжный режим;
- нарезка по главам для Yoto для любой книги;
- для публичных примеров — голос с открытой лицензией (NST, CC0).

Идеи, по убыванию пользы для ребёнка:

1. **Подсветка по словам (караоке).** Whisper умеет `word_timestamps`,
   Piper отдаёт фонемы с длительностями — можно подсвечивать текущее
   слово, а не только строку. Сильно помогает учиться читать.
2. **Тап по шведскому слову — перевод.** Глоссарий книги (`glossary.md`
   уже делается при переводе) -> всплывашка со словом, переводом и
   озвучкой слова.
3. **Режим «повтори».** Пауза после каждой строки (длина = длительность
   строки), чтобы ребёнок повторил вслух; кнопка повтора текущей строки.
4. **Слова главы.** После главы — 5–10 новых слов с картинками из сцен;
   экспорт в карточки (например, в тренажёр m5svenska).
5. **Разные голоса персонажей** в TTS-маршрутах: разметка
   `[morfar]` в `chNN.txt` -> свой голос Piper (или облачный TTS с
   эмоциями) на реплики.
6. **PWA / офлайн.** Манифест + service worker: книга на домашнем экране
   iPad, работает без сети.
7. **QR-коды в PDF.** На каждой странице бумажной книги — QR со ссылкой
   `index.html#t=…`: навёл телефон — слушаешь с этого места.
8. **Колонтитул с таймкодом страницы в PDF** (был в старом `robin_pdf` на
   pagedjs; в Chrome нет `string-set`, поэтому сейчас таймкод у абзаца).
9. **Автозапуск Codex.** Когда установлен `codex` CLI — `codex exec` с
   промптами из `prompts/` прямо из Claude Code, без копирования вручную.
10. **Иконки треков для Yoto** по сюжету главы (пример — пиксельные
    иконки Robin, `books/robin/extras/yoto_art.py`) — генерировать тем же
    процессом через Codex.
