# Claude: проверка иллюстраций

```
Собери контакт-лист сцен книги books/<slug>:
python3 tools/contact_sheet.py books/<slug>/illustrations/ch*/*.png -o /tmp/<slug>-scenes.png --cols 4
и сравни каждую картинку с bible.md, refs/*.png и текстом вокруг якоря
(build/data.json). Ищи: кто лишний/кого нет, несоответствие внешности,
одежды, локации, предметов референсам; противоречие тексту (время суток,
погода, что происходит); артефакты (руки, текст).

Результат — готовый промпт для Codex по шаблону prompts/codex-fix.md со
списком сцен и конкретной правкой для каждой. Хорошие сцены не трогать.
```
