# Claude: сцены

После того как референсы зафиксированы (`bible.md` — LOCKED).

```
Прочитай books/<slug>/illustrations/bible.md и текст книги. Составь
books/<slug>/illustrations/scenes.json по образцу
examples/ella-och-draken/illustrations/scenes.json:

- <N> сцен на главу (по умолчанию 3–6; для коротких глав меньше),
  равномерно по главе, на ключевых и зрелищных моментах; не две похожие
  подряд.
- id "<глава>-<номер>", file "chNN/MM.png", chapter, pos (after — картинка
  после строки, before — перед).
- anchor — уникальный фрагмент строки перевода, после/перед которой стоит
  картинка (проверка: python3 tools/illustrations_status.py books/<slug>).
- refs — id референсов из библии, нужных в сцене (characters, loc-..., prop-...).
- prompt (англ.) — только действие, композиция, эмоции, свет. Внешность
  персонажей, локаций и предметов НЕ описывать заново — она берётся из
  референсов. Явно перечислить, кого в сцене НЕТ, если генератор может их
  дорисовать (см. «Правила для сцен» в библии).
- Сверить с текстом: кто реально присутствует, время суток, одежда по
  сюжету (пижама, куртки), погода.
```
