# Claude: библия иллюстраций

Первый шаг иллюстраций. Всё, что повторяется в книге, описывается один раз,
получает id и потом свой референс-лист. Пример — `examples/ella-och-draken/illustrations/bible.md`.

```
Прочитай книгу books/<slug>/text/ (или build/data.json) целиком и составь
books/<slug>/illustrations/bible.md по образцу
examples/ella-och-draken/illustrations/bible.md:

1. Стиль: одна строка STYLE для всех картинок + негатив. Предложи 2–3
   варианта стиля (акварель, гуашь+карандаш, цифровая плоская...),
   основным поставь тот, что лучше подходит книге и возрасту ребёнка.
2. Персонажи: все, кто появляется в 2+ сценах. id, кто, в каких главах,
   описание для промпта на английском: возраст, рост/телосложение, волосы,
   кожа, глаза, одежда (одна постоянная), отличительная деталь. Сначала
   выпиши всё, что сказано в тексте (с цитатой и главой); недостающее
   придумай, не противореча тексту и между собой. Животные — тоже персонажи.
3. Локации: места, где происходят 2+ сцены (дом, комната, школа, площадка...).
   Описание: архитектура, цвета, ключевые детали, которые должны совпадать
   от картинки к картинке.
4. Предметы: всё, что повторяется и важно для сюжета (игрушка, машина,
   изобретение, рюкзак...). Форма, цвет, размер, узнаваемые детали.
5. Для каждого элемента — путь будущего референса: refs/characters.png
   (все персонажи на одном листе; если их больше 6 — refs/characters-2.png),
   refs/loc-<id>.png, refs/prop-<id>.png.
6. Правила для сцен: кого генератор склонен дорисовывать лишним, что нельзя
   путать (близнецы, похожие взрослые).

Статус всего документа — DRAFT. Ничего не генерируй.
```
