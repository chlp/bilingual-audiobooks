# Codex: перегенерация сцен

Шаблон (обычно его заполняет Claude по итогам проверки):

```
Перегенерируй сцены книги books/<slug> с референсами refs/<id>.png из поля
refs каждой сцены (scenes.json) и STYLE из bible.md. Сохрани поверх
существующих файлов.

- <id> (<file>): <что не так> -> <как должно быть>.
  Добавь в промпт: "<явное уточнение, например: Morfar is NOT in this scene>".
- ...
```

После: `python3 tools/build_html.py books/<slug>` — плеер подхватит новые
картинки (уменьшенные копии пересоздаются по дате изменения).
