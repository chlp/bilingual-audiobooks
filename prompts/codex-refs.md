# Codex: варианты референс-листов

Запускать в приложении Codex (нужен skill `imagegen`), рабочая папка —
корень этого репозитория. Перед этим Claude написал `illustrations/bible.md`.

```
Прочитай AGENTS.md и books/<slug>/illustrations/bible.md.

Сгенерируй варианты референс-листов, ничего не перезаписывая:
1. Персонажи: 3 варианта листа со всеми персонажами из таблицы
   «Персонажи» -> books/<slug>/illustrations/refs/characters-v1.png, -v2, -v3.
   Полный рост, вид спереди, белый фон, персонажи в ряд с промежутками,
   без подписей и текста, пропорции возраста как в описании. Варианты
   отличаются трактовкой внешности и стилем в рамках STYLE (v3 — в
   альтернативном стиле из библии).
2. Каждая локация с листом: 2 варианта -> refs/loc-<id>-v1.png, -v2.png
   (общий план, без людей, 3:2).
3. Каждый предмет с листом: 2 варианта -> refs/prop-<id>-v1.png, -v2.png
   (предмет крупно, 2–3 ракурса на одном листе, белый фон).

В конце собери контакт-лист:
python3 tools/contact_sheet.py books/<slug>/illustrations/refs/*-v*.png -o books/<slug>/illustrations/refs/_variants.png
и перечисли созданные файлы.
```

Дальше человек выбирает варианты (можно смешивать: «персонажи v2, но у Эллы
причёска из v1» -> попросить Codex доработать v2). Выбранное копируется в
`refs/characters.png`, `refs/loc-<id>.png`, `refs/prop-<id>.png`; Claude
переводит библию в статус LOCKED и уточняет описания по выбранным картинкам.
