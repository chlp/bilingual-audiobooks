# Claude: перевод сегмент-в-сегмент (маршрут A)

Есть `build/sv.json` из `tools/transcribe.py` — реплики с точными таймкодами.

```
Переведи books/<slug>/build/sv.json на русский -> books/<slug>/build/ru.json.

Контракт: JSON-массив той же длины и в том же порядке; у каждого элемента
те же start/end, что у элемента sv.json, и text — перевод. Не объединяй и не
разбивай сегменты, не добавляй и не убирай реплики, даже если по-русски
естественнее иначе — иначе разъедется синхронизация с аудио. Заголовки глав
("Kapitel N ...") переводи на своём месте как "Глава N. ...".

Сначала прочитай всю книгу целиком, составь глоссарий имён и повторяющихся
слов (books/<slug>/build/glossary.md) и держи его во всех главах. Переводи по
главам, после каждой проверяй длину: python3 -c "import json;
print(len(json.load(open('sv.json'))), len(json.load(open('ru.json'))))".

Попутно выпиши в build/asr-fixes.md места, где Whisper явно ошибся
(бессмыслица, обрывы, повторы) — с таймкодом и предложенной правкой sv.json.
```

После: `python3 tools/build_data.py --sv build/sv.json --ru build/ru.json --title "..." --out build/data.json`.
