# Claude: текст книги -> пары «оригинал ||| перевод»

Маршруты B и C (озвучиваем сами). Источник — расшифровка аудио на другом
языке (`build/<lang>.json` / `.srt`), текст книги или своя история.

```
Подготовь текст книги в books/<slug>/text/ по формату guide/FORMATS.md
(раздел chNN.txt). Источник: books/<slug>/source/<файл>.

- Один файл на главу: ch01.txt, ch02.txt, ...
- Первая строка — заголовок: "Kapitel N. Название ||| Глава N. Название".
  Перед ним в ch01.txt строка "@Автор. Название книги ||| ..." (вступление).
- Дальше по одному предложению на строку: "шведский ||| русский",
  абзацы через пустую строку. Реплика диалога — отдельной строкой с "– ".
- Шведский — естественный, простой, для ребёнка 5–8 лет; русский —
  литературный, но строго тот же смысл, что у шведской строки этой же
  строки (строки читаются параллельно).
- Длинное предложение (больше ~20 слов) разбей на два: TTS и подсветка
  в плеере работают по строкам.
- Имена — как в оригинальной книге (если источник — перевод, верни
  оригинальные имена и отметь это в book.json, поле "about").
- Цифры, сокращения и даты в шведском пиши словами — так их правильно
  прочтёт TTS.

Переводи по главам; после каждой главы запускай
`.venv-tts/bin/python tools/tts_build.py books/<slug>` — он проверит формат.
```
